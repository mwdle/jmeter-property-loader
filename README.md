# JMeter Property Reader plugin

Property File Reader plugin for JMeter. Allow users to select a property file (.properties) and parse the content to be JMeter compatible properties.

## Usage
- Use Maven to package the project in a .jar file
- Copy the .jar file to `JMETER_HOME/lib/ext` folder
- Add new `Config Element` > `Property File Reader`
